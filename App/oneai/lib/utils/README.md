# Utils

This directory contains utility classes and helper functions used throughout the application:

- `result.dart`: Result type for error handling and functional programming pattern
- `result.freezed.dart`: Generated code for the Result type
- `logger.dart`: Logging utility for consistent application logging
- `loading_manager.dart`: Manager for tracking loading states across operations
- `loading_manager.freezed.dart`: Generated code for the LoadingManager

These utilities are generally stateless and provide reusable functionality across all layers of the application.
