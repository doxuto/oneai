# Use Cases

This directory contains use case implementations that encapsulate the business logic of the application.

Use cases represent the business rules and application-specific logic. They orchestrate the flow of data between entities and repositories, implementing the core functionality of the application.

Use cases are:
- Independent of frameworks, UI, or external agencies
- Testable business rules without UI, database, web server, or any external element
- Focused on a single responsibility or feature

Each use case typically follows the Single Responsibility Principle and represents one specific action that can be performed in the application.
