# Themes

This directory contains theme-related configurations and utilities:

- `dark_theme.dart`: Dark theme implementation
- `light_theme.dart`: Light theme implementation
- `dimens.dart`: Dimension constants for consistent spacing (e.g., gapW, gapH)
- `theme_extension.dart`: Extensions for accessing theme properties
- `theme_helpers.dart`: Utility functions for theme management
- `typography.dart`: Text style definitions

Use these theme utilities to maintain consistent styling throughout the application.
