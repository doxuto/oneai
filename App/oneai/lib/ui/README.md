# UI

This directory contains all user interface components:

- `core/`: Core UI components, themes, and shared widgets
- `feature_name/`: Feature screen components

Each subdirectory typically follows a feature-first organization approach.

## Structure:

Each subdirectory contains:
- `view_models/`: Contains ViewModels that manage the state and business logic for screens.
- `widgets/`: Reusable UI components specific to the feature.
